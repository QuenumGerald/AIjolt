# Planches personnage (`refs/`)

Dépose ici **1 à 3 images** stables (PNG/JPG) :

1. `face-sheet.png` — visage + expression neutre (idéalement plusieurs angles)
2. `full-body.png` — corps entier avec la tenue signature
3. (optionnel) prop / companion sheet

Puis mets à jour les chemins dans `character.json` → `referenceImagePaths`.

Sans planche, le pipeline refuse un run live (DRY_RUN reste possible).
